About

Savepaste is a simple and secure image hosting platform that allows you to paste, view, and download images without storing them on the server.

How to Use

Paste an image with Ctrl + V. It downloads right away and its filename is copied to your clipboard.

Shortcuts

  • D download again
  • C copy image to clipboard
  • P / J / W save as PNG / JPEG / WebP (strips metadata)
  • ← → previous / next paste
  • O open an image file
  • L set downloads folder, so the full path is copied
  • Esc clear
  • ? show / hide this panel

FAQs

  • What image formats are supported? Any image your browser can display: PNG, JPEG, GIF, WebP, AVIF and more.
  • Are images stored on the server? No, images are only available during the current session.
  • Can I download the pasted images? Yes, you can download the images directly from the browser.
